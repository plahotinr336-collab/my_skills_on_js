# Frontend Examples for T-Start

Этот репозиторий содержит примеры моего кода для программы стажировки Т-Старт.

## Содержание

- **useFetch** — кастомный хук для работы с API с поддержкой AbortController
- **SearchInput** — оптимизированный компонент поиска с debounce
- **SecureStorage** — обертка над localStorage с TTL и типизацией
